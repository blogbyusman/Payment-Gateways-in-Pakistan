## 🚀 How to Deploy on GitHub Pages

### Step 1 — Create a Repository
1. Go to [github.com](https://github.com) and sign in
2. Click the **+** icon → **New repository**
3. Name it `your-username.github.io` *(replace with your actual GitHub username)*
4. Set it to **Public**
5. Click **Create repository**

### Step 2 — Upload the File
1. Inside the repo, click **Add file → Upload files**
2. Drag and drop `index.html` and `README.md`
3. Click **Commit changes**

### Step 3 — Enable GitHub Pages
1. Go to **Settings** (top menu of your repo)
2. Scroll down to **Pages** (left sidebar)
3. Under **Source**, select `main` branch and `/ (root)` folder
4. Click **Save**

### Step 4 — Your Blog is Live 🎉
Wait 2–3 minutes, then visit:
```
https://your-username.github.io
```

## ✏️ How to Customize

| What to Change | Where to Find It |
|---|---|
| Blog title & content | Inside `<main>` in `index.html` |
| Colors & fonts | `:root` CSS variables at the top of `<style>` |
| Site logo name | `.site-logo` in the `<header>` |
| Meta description & keywords | `<head>` section |
| Footer text | `.site-footer` at the bottom |

### Change the Color Theme
Open `index.html` and edit the CSS variables at the top of the `<style>` block:

```css
:root {
  --green-700: #1D9E75;   /* Main accent color */
  --blue-600:  #185FA5;   /* Secondary accent */
  --gray-900:  #1A1A18;   /* Body text color */
}
```
